# À L'Abordajeux — Subscription API

FastAPI + SQLite service for anonymous, capacity-tracked event signups.

Hosted on a Raspberry Pi behind a Cloudflare Tunnel. Serves the static site
([abordajeux.github.io](https://github.com/abordajeux/abordajeux.github.io)) via CORS-enabled
JSON endpoints.

## Status

Pre-development — spec phase. See `AGENTS.md` for the spec location and architecture context.
